01

About

Half my week is at the bench, half is in a terminal.

I'm doing my Ph.D. at the Universidad de La Laguna. We screen small molecules against human tumour cell lines, and I build the pipelines that turn plates, images and sequencing reads into a decision: which compounds are worth another round, and why they work.

That means SRB assays and fluorescence microscopy on one side, and Python, R, deep learning and transcriptomics on the other. I've worked on anticancer compounds with groups in Europe, Asia and Latin America.

02

Work
problem → method → output

Things I've built to answer real questions

ColonyVision Python · computer vision

Problem
Counting colonies on plates by hand is slow and changes from one person to the next.
Method
Image segmentation pipeline that detects and counts colonies from plate photos.
Output
Reproducible counts and stats per condition, ready for the figure.
Code private · available on request →

Cell cycle & apoptosis from DAPI Python · imaging

Problem
Telling whether a compound arrests the cycle or kills cells, from one stain.
Method
Nuclear segmentation and DNA-content profiles from DAPI images.
Output
Cycle phase and apoptosis fractions per treatment.
Code private · available on request →

Melanoma molecular network R · networks

Problem
Finding which genes and pathways hold melanoma's signalling together.
Method
Construction and analysis of a molecular interaction network.
Output
Hub genes and modules to prioritise as targets.
Code private · available on request →

RNA-seq for mechanism of action R · DESeq2

Problem
A compound kills cells — but through which pathway?
Method
Differential expression and enrichment on treated vs. control cells.
Output
A transcriptional signature that points to a mechanism.
Code private · available on request →
